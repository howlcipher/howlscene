# Create a Cinematic Story

1. In the editor, choose **Cinematic Story** under **Start from a template**.
2. Choose Ink Wash, Cyberpunk, or Modern Professional under **Visual theme**.
   Theme changes keep your scenes and writing.
3. Select a scene in **Website sections**. Change its heading and edit the rich
   text. Use the section controls to move, duplicate, or delete scenes.
4. Choose **Change scenery** to upload artwork. Set **Image treatment** to
   **Background scenery**, then adjust **Image position** when needed. Add an
   image description if it conveys information.
5. Choose a **Scene layout** and **Transition style**. The transition controls
   are preset choices; they do not accept scripts or custom code. In a
   Cinematic Story, **Change transition cover** adds a decorative image layer
   that briefly clears as a scene enters. It is hidden from assistive
   technology and does not replace the scene's scenery or text.
6. Adjust motion intensity and speed in the appearance controls. The website
   respects the device's reduced-motion preference and offers a manual motion
   control in the enhanced exported site.
7. Preview at phone, tablet, and desktop widths. The page keeps ordinary
   scrolling and scene links; it does not lock the browser into a carousel.
8. Your project saves in this browser when local storage is available. Download
   a project backup to keep an editable copy. Download the separate website ZIP
   to publish the static site; its content and supported transition settings
   come from the shared renderer.

The starter has five editable scenes. The project model supports between one
and 100 sections, subject to the existing project and asset limits. Empty
headings, long text, theme readability, and uploaded imagery should be reviewed
in preview before publishing.

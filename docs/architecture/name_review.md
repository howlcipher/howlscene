engineering discovery record, not a claim of trademark clearance or exclusivity.

  unrelated music track titled “howlscene” on the
  [Sleep Clinic release](https://crlss.bandcamp.com/album/mke-sleep-clinic).
  That query did not establish an existing software product with this name;
  search coverage is incomplete.
- `npm view @howlscene/core version` returned registry E404: no publicly accessible
  package was found at that name. This does not reserve the scope, prove package
  publication rights, or rule out private resources.
- The actual standalone source repository is
  [howlcipher/howlscene](https://github.com/howlcipher/howlscene). No ownership
  claim over unrelated uses of “HowlScene” is asserted.

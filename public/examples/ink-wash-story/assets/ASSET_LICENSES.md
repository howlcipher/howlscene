# Sample artwork provenance

These six original landscape illustrations were generated for the HowlScene
sample using OpenAI's built-in image generation tool on 2026-10-30. They were
prompted as new artwork and were not extracted from or copied from the supplied
reference video. The optimized WebP files in this directory are included in the
HowlScene source and sample website distribution.

| File                    | Subject                                     | Export   |
| ----------------------- | ------------------------------------------- | -------- |
| `stone-bridge.webp`     | Misty canal, stone bridge, and covered boat | Included |
| `clocktower-river.webp` | Old riverside town and clock tower          | Included |
| `moon-gate.webp`        | Garden pavilion and moon gate               | Included |
| `river-city.webp`       | Historic riverfront skyline                 | Included |
| `dusk-skyline.webp`     | Fictional modern skyline at dusk            | Included |
| `mist-cover.webp`       | Original fog-valley transition cover        | Included |

No third-party image or font service is required by the sample.
